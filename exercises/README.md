# Exercises

Each `chapter-XX.hs` file contains the five exercises for that chapter with `undefined` placeholders.

Load one in GHCi:

```haskell
:l exercises/chapter-01.hs
```

Replace each `undefined` with your implementation, then reload:

```haskell
:r
```

If a function still returns `undefined`, GHCi will throw an exception when you call it. That is expected until you fill it in.

The exercise statements live in the chapter markdown files under `book/`. Read the chapter first, then open the matching exercise file.
